# Pane Canonical Schema — Pre-Launch (v1.0)

*Line citations predate the #3097 module split.*

**Version:** 1.0  
**Created:** 2026-04-18  
**Status:** CANONICAL — Single source of truth for all Pane database tables  
**Scope:** Pre-launch (zero customers, delete-and-recreate on mismatch)

---

## Overview

This document defines **EVERY** table Pane needs with **EVERY** column, **EVERY** index, and **EVERY** constraint. It is the single source of truth for `migrate_fresh_install()` in `migrations.rs`.

**Pre-launch rules (§2B.3 of architecture spec):**
- ONE canonical schema definition
- NO migration chain
- ON mismatch: delete and recreate fresh
- Notes live in markdown files — nothing is lost
- CRR enabled AFTER table creation — no ALTER needed
- **CRR tables CANNOT have UNIQUE or FOREIGN KEY constraints** — cr-sqlite rejects both. Enforce in application code (#493)
- **CRR tables: every NOT NULL column must have a DEFAULT value** — cr-sqlite requires this for forward/backward sync compatibility
- **Projects/folders are never deleted, only archived** — eliminates most cascade scenarios

**What's NOT included:**
- CRR metadata tables (`__crsql_clock`, `__crsql_pks`, etc.)
- CRR triggers (auto-generated by `crsql_as_crr()`)
- `schema_migrations` table (being removed pre-launch)
- `migration_failures` table (being removed pre-launch)
- Dead tables: `folder_preferences` (consolidated → `projects.is_hidden`)
- Dead tables: `project_settings` (consolidated → `projects.default_model`, `smart_routing_enabled`, etc.)

## Core Content Tables

### projects
- **Purpose:** Top-level containers for notes and folders (recursive hierarchy)
- **CRR:** yes
- **Used by:** `notes.rs`, `ai/commands.rs`, `dashboard.rs`, `commands.rs`
- **Changes in v0.60.0:** Added `is_hidden` (from `folder_preferences`), `default_model`, `smart_routing_enabled`, `router_model`, `simple_tier_model` (from `project_settings`)

```sql
CREATE TABLE IF NOT EXISTS projects (
    id                    TEXT PRIMARY KEY,
    name                  TEXT NOT NULL,
    description           TEXT,
    color                 TEXT,
    parent_id             TEXT,
    sort_order            INTEGER NOT NULL DEFAULT 0,
    owner_id              TEXT,
    
    created_at            TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at            TEXT NOT NULL DEFAULT (datetime('now')),
    
    category              TEXT,
    is_system             INTEGER NOT NULL DEFAULT 0,
    
    -- Consolidated from folder_preferences (#486 v0.59.0)
    is_hidden             INTEGER NOT NULL DEFAULT 0,
    
    -- Consolidated from project_settings (#486 v0.59.0)
    default_model         TEXT,
    smart_routing_enabled INTEGER,
    router_model          TEXT,
    simple_tier_model     TEXT,
    
    -- NOTE: No FOREIGN KEY on parent_id — CRR table, enforce in app code (#493)
    -- NOTE: No UNIQUE(name, parent_id) — cr-sqlite CRR tables cannot have
    -- unique constraints beyond primary key. Uniqueness enforced in application
    -- code instead (see #493).
);
```

**Indexes:**
```sql
CREATE INDEX IF NOT EXISTS idx_projects_name ON projects(name);
CREATE INDEX IF NOT EXISTS idx_projects_parent ON projects(parent_id);
CREATE INDEX IF NOT EXISTS idx_projects_hidden ON projects(is_hidden) WHERE is_hidden = 1;
```

    folder_id       TEXT,

    status          TEXT,
    priority        TEXT,
    due_date        TEXT,
    assignee        TEXT,
    completed_at    TEXT,
    sort_order      INTEGER NOT NULL DEFAULT 0,
    
    word_count      INTEGER NOT NULL DEFAULT 0,
    pinned          INTEGER NOT NULL DEFAULT 0,

    parent_id       TEXT,
    note_type       TEXT,
    is_vital        INTEGER NOT NULL DEFAULT 0,
    agent_id        TEXT,                       -- #280: agent ownership, NULL = user-owned
    
    -- NOTE: No FOREIGN KEY on folder_id or parent_id — CRR table, enforce in app code (#493)

## Search Tables (FTS5)

### notes_fts
- **Purpose:** Full-text search on note title and body
- **CRR:** no (FTS5 external content table, rebuilt on startup)
- **Used by:** `ai/commands.rs` (rebuild triggers in migration 026)
- **External content table:** Tied to `notes` table via `content='notes'`

```sql
CREATE VIRTUAL TABLE IF NOT EXISTS notes_fts USING fts5(
    title,
    body,
    content='notes',
    content_rowid='rowid',
    tokenize='porter unicode61'
);
```

**Triggers (auto-maintain FTS5 from notes table):**
```sql
CREATE TRIGGER IF NOT EXISTS notes_fts_insert AFTER INSERT ON notes BEGIN
    INSERT INTO notes_fts(rowid, title, body) VALUES (new.rowid, new.title, new.body);
END;

CREATE TRIGGER IF NOT EXISTS notes_fts_delete AFTER DELETE ON notes BEGIN
    INSERT INTO notes_fts(notes_fts, rowid, title, body) VALUES('delete', old.rowid, old.title, old.body);
END;

CREATE TRIGGER IF NOT EXISTS notes_fts_update AFTER UPDATE ON notes BEGIN
    INSERT INTO notes_fts(notes_fts, rowid, title, body) VALUES('delete', old.rowid, old.title, old.body);
    INSERT INTO notes_fts(rowid, title, body) VALUES (new.rowid, new.title, new.body);
END;
```

## AI Chat

### chat_messages_local
- **Purpose:** Chat messages (local-only, not synced via CRR)
- **CRR:** no (intentionally local-only)
- **Used by:** `ai/commands.rs`, `lib.rs`
- **Note:** Per-device chat history, not synced. Added `thread_id` in migration 025, `agent_id` in migration v76 (#2030), `oc_message_id` in migration v84 (#2410, §30.11.2).

```sql
CREATE TABLE IF NOT EXISTS chat_messages_local (
    id          TEXT NOT NULL PRIMARY KEY,
    project_id  TEXT NOT NULL DEFAULT '',
    role        TEXT NOT NULL DEFAULT 'user',
    content     TEXT NOT NULL DEFAULT '',
    created_at  TEXT NOT NULL DEFAULT (datetime('now')),
    is_pinned   INTEGER NOT NULL DEFAULT 0,
    attachment_ids TEXT,
    tool_calls  TEXT,
    tool_results TEXT,
    model       TEXT,
    token_count INTEGER,
    thread_id   TEXT,
    agent_id    TEXT REFERENCES ai_agents(id),
    oc_message_id TEXT
);
```

**Indexes:**
```sql
CREATE INDEX IF NOT EXISTS idx_chat_local_project ON chat_messages_local(project_id, created_at);
CREATE INDEX IF NOT EXISTS idx_chat_local_thread ON chat_messages_local(thread_id, created_at);

-- §30.11.2 (#2410): dedup key for externally-ingested (proactive/OC-transcript-pull)
-- messages via ingest_external_messages. Partial unique index — NULL oc_message_id
-- (ordinary user/assistant messages) is excluded and never deduped.
CREATE UNIQUE INDEX IF NOT EXISTS idx_chat_local_oc_dedup
    ON chat_messages_local(thread_id, oc_message_id)
    WHERE oc_message_id IS NOT NULL;
```
