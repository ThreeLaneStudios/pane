Design Notes:
- Fixed card heights per option (A: 68px, B: 88px, C: 96px). Empty metadata uses visibility:hidden to reserve space.
- Option A: Most compact, best for density. Status badge in title row, everything else in pill strip.
- Option B: Preview text gets dedicated row. Status moves to metadata strip. Best for content-heavy notes.
- Option C: Labeled grid gives structure. Best for metadata-heavy workflows. Subtask count could be added as 3rd grid row.
- Hover: slight background brighten. Selected state (not shown): teal left border accent.
