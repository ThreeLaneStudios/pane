Narrow State — Dropped Metadata:
- Preview text: Dropped in ALL narrow options (not enough width for meaningful preview)
- Assignee: Dropped in ALL narrow options (visible in editor detail pane instead)
- Subtasks: Dropped in B and C (kept in A which has more horizontal room)
- Date format: Shortened from "2026-04-02" to "Apr 02" to prevent wrapping
- Kept in all: Title, status badge, folder, date, priority — these are the core scannable fields

Recommendation: Option B (Compact Strip) is the sweet spot for narrow — clean, scannable, no wasted space. Option A if subtask visibility matters. Option C if users need labeled clarity at small sizes.
