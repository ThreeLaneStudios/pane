Onboarding flow

The first-run experience needs to feel lightweight. Users should be able to create their first note within 10 seconds of opening the app. No sign-up walls, no tour modals.

Key steps: welcome screen → create first note → show card preview → introduce folders. Keep it to four screens max. Animation between steps should be 200ms ease-out.

Consider a skip option for power users who want to jump straight to the workspace.
